## Where the numbers land

Every link above goes through `/go/<code>`, which redirects to the homepage
carrying UTM parameters. Umami reads them.

| Posted as | Code | Shows up as |
|---|---|---|
| YouTube, main upload | `/go/yt` | youtube / social / main-upload |
| YouTube Shorts | `/go/yts` | youtube / social / shorts |
| LinkedIn | `/go/li` | linkedin / social / post |
| X | `/go/x` | x / social / post |
| TikTok bio | `/go/tt` | tiktok / social / bio |
| Instagram bio | `/go/ig` | instagram / social / bio |
| Facebook | `/go/fb` | facebook / social / post |

Read them in Umami under **Reports**, then the **UTM** report, filtered to
campaign `launch-2026`.

**Do not rely on the referrer instead.** Links opened inside the TikTok,
Instagram and Facebook in-app browsers arrive with no referrer or a generic app
one, and this site sends `strict-origin-when-cross-origin`. The UTM parameters
are in the URL, so they survive all of that. That is the whole reason the
`/go/` codes exist.

**Test each code once before posting.** Open it, confirm you land on the
homepage with the parameters still in the address bar, and confirm the visit
appears in Umami. A redirect that 404s loses the click silently.

## Before you post

- [ ] Watch each file to the end with sound on
- [ ] Confirm the vertical captions are visible above the platform UI
- [ ] Check the shop is up: https://shop.lebon-grace.com
- [ ] Make sure stock levels and the AED 15 price are still true
- [ ] Have someone ready to answer comments for the first few hours

**One caveat worth holding.** These films are strongest on the promise, and the
promise is checkable, which is why every caption is a fact. If any of them
stops being true (the price, the lead time, the free engraving), the films stop
being usable and should come down rather than be quietly left up.

How a request actually reaches the shop

TLS terminates in Mumbai. The application runs in Nuremberg. The tunnel between them is opened from the inside out, which is why nothing needs a public port on the Hetzner box.

Why it is built this way

The tunnel dials out

  • cx53 opens the SSH connection to the AWS box, not the other way round.
  • So the Hetzner host needs no public port and no inbound rule for the shop.
  • The cost is a dependency: if the tunnel drops, Caddy answers 503.

Deploying

Two resources, one name

  • Production is the Coolify service, running a prebuilt image.
  • The Coolify application of a similar name builds from git and serves nothing.
  • Every NEXT_PUBLIC_* is baked in at build time, not at run time.

Adjacent, not shown

R2 media

  • Launch films live in a Cloudflare R2 bucket, served straight to the social platforms.
  • Uploaded by scripts/social, outside the request path entirely.
